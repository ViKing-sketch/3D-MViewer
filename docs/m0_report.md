# M0. Прототип on-device OCCT

Статус: **не выполнялся**.

ТЗ (этап M0) требует сборку OCCT 7.8.1 под Android NDK, импорт STEP через XDE на устройстве и сравнение с заранее сконвертированным GLB в Filament. Нужны не меньше двух устройств и трёх моделей (малая / средняя / крупная). В этой среде нет NDK-сборки OCCT и нет прогона на устройствах, поэтому решения go/no-go по объёму OCCT на устройстве нет. Числовые цели раздела 9 ТЗ остаются допущениями [П].

Пресет CMake `android-arm64` подключает toolchain NDK (`ANDROID_NDK_HOME`) и останавливается с понятной ошибкой, если NDK нет. Superbuild хоста описан в `deps/CMakeLists.txt` и по умолчанию выключен.

Когда прогон появится, отчёт заполняется так:

| Модель | Устройство | Загрузка STEP, с | Пик RSS, МБ | Триангуляция, с | FPS | Размер .so, МБ |
| --- | --- | --- | --- | --- | --- | --- |
| малая | | | | | | |
| средняя | | | | | | |
| крупная | | | | | | |

Рядом — те же модели, открытые как GLB в Filament, и вывод: оставляем ли на устройстве только чтение `brep.pack` (рекомендация риска R1) или допускаем on-device STEP.
