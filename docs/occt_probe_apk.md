# Тестовый APK с пробой OCCT

Это не просмотрщик и не релиз. Файл `tools/occt_probe_apk/field-bim-occt-probe-arm64.apk` — отладочный пакет только для `arm64-v8a`. Внутри бинарник пробы, собранный под Android API 28 (метка ELF `0x1c`, NDK 28.2), и девять библиотек OCCT плюс `libc++_shared.so`. Сборка пробы — ящик 1×2×3 м, ожидаемые объём 6 м³ и площадь 22 м². На телефон отсюда никто не ставил этот пакет и к телефону не подключался.

## Как поставить

1. Скопируйте APK на телефон (почта, кабель, как удобно). Телефон — arm64, Android 9 или новее.
2. Откройте файл на телефоне и разрешите установку из этого источника, если система спросит.
3. Запустите приложение «OCCT probe».

## Что прислать

Нажмите «Запустить пробу». Пришлите текст с экрана или снимок экрана. В удачном выводе есть строка с `volume_m3=6`, `area_m2=22` и `exit=0`. Если вместо неё ошибка загрузки библиотеки или `exit` не 0, пришлите текст целиком: этого достаточно, отдельно подключаться к телефону не нужно.
