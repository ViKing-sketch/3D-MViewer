## Нефункциональные и этапы

NFR-02…NFR-06, NFR-08…NFR-10, NFR-16 на устройстве не измерялись. Цели с пометкой [П] остаются допущениями: M0 не выполнен. NFR-11 (Android 9, arm64-v8a, уровень Note 10+) в манифесте заявлен как minSdk, прогон на таком устройстве не записан.

| Этап | Статус |
| --- | --- |
| M0 | Не выполнен как прототип STEP/XDE на устройствах. Есть хостовый бенчмарк мешера и отдельная сборка OCCT 7.8.1 под NDK. Коробка и BinTools прогнаны на эмуляторе Android 9 x86_64 (API 28) и на эмуляторе Android 8.1 arm64-v8a (API 27, перевод на x86_64). Бинарник API 28 arm64 на Android не запускался. Формат геометрии не менялся |
| M1 | Частично: IFC-мешер и пакет format_version 1. Нет STEP, настоящего B-Rep, второго LOD и тайлов. GUI конвертера — страница со списком и журналом, без процента по элементам |
| M2 | Частично: S1 со списком (размер, дата, план AABB; `thumbs/` нет), S3 в урезанном виде. S7: сводка и CSV в папку, которую выбирает пользователь (на Android — системный документ). S4: поиск по имени, марке, GlobalId и значению свойства через FTS5. S2: этаж, класс, материал и система (членство только в format_version 2; версия 1 открывается). Навигация FR-M-03 включает ходьбу по этажу без столкновений. Приёмка NFR на устройстве не снята |
| M3 | Не начат. Сечение — только clip plane, без контура |
| M4–M6 | Не начаты. M6 включает MLT, DWG/DXF, IGES и ИБ по отдельному запросу |
