## Готово

- Конвертер IFC: свой разбор и, при `FBV_WITH_IFCOPENSHELL`, IfcOpenShell 0.8.5 + OCCT 7.8.1 (FR-C-01, частично: не вся геометрия IFC). Local origin, метры, GlobalId (FR-C-06). `pkg_validate` (FR-C-09). Лог и коды 0/2/3/4 (FR-C-08). CLI: точность, класс, мешер, потоки, память (FR-C-10). Docker и CI Linux/Windows, в том числе IfcOpenShell (FR-C-11).
- SQLite: дерево, этажи, типы, Pset/Qto, материалы, классификация, FTS5, `spec_views` (FR-C-04, FR-C-07). Системы — format v2. Тайл = этаж × дисциплина — format v3, индекс есть (FR-C-15, частично). BinTools формы OCCT — format v4, пишет сборка с IfcOpenShell; аналитический мешер оставляет слот пустым (FR-C-05, частично). `brep.pack` по-прежнему AABB.
- Оболочка: страница «Конвертер», две стадии прогресса, не процент по элементам (FR-C-14, частично).
- Android, Filament 1.77.3, не заглушка: орбита, панорама, зум, виды, «вписать», ходьба по этажу с двумя экранными джойстиками (без проверки столкновений, шаг проходит сквозь стены) (FR-M-03). Касание, свойства, Pset/Qto (FR-M-04). Дерево, скрыть, изолировать, рентген (FR-M-05; сборок STEP нет). Фильтры этаж, класс, материал, система (FR-M-06). Поиск FTS5 (FR-M-07). Сводка и CSV (FR-M-08). Одна плоскость сечения, без контура OCCT (FR-M-11, частично). Книжная и альбомная ориентация, тёмная и контрастная тема (FR-M-12, частично; планшет отдельно не гоняли). Бюджет GLB и коробочные заглушки, без LOD по расстоянию (FR-M-13, частично). Русский и английский (FR-M-19, NFR-14).
- Импорт SAF и «Поделиться», список с датой и планом AABB, не снимок (FR-M-01, частично). Просмотр без сети (FR-M-02, NFR-01).
- Замечания, фото, ракурс, BCF 2.1 (FR-M-15, S8).
- Именованные виды (FR-M-14): камера, фильтры, скрытые и изолированные, рентген и одна уже существующая плоскость среза пишутся в `<пакет>.views.json` рядом с пакетом. Это не замечание, не BCF и не файл внутри `.fbvpkg`. Открытие возвращает орбиту. Поиск по свойствам в вид не входит и при открытии снимается. `fbv-sync-1` этот файл не передаёт. Нескольких плоскостей сечения по-прежнему нет.
- Синхронизация `fbv-sync-1`: пакеты, замечания, BCF; новее по времени; SHA-256; запись через временный файл (FR-C-17, FR-M-18, NFR-15, частично). Обрыв оставляет прежний файл и уже полученные байты в `.fbv-sync-parts`; следующий забор продолжает с `Range`. USB нет. Файл именованных видов в обмен не входит.
- Сцена с тайлами (FR-C-15 остаток, #33): пакет format v3 и новее не кладёт `lod0.glb` в Filament. Выбранный этаж — один тайл этаж × дисциплина. «Все этажи» берёт тайлы по порядку, пока их меши влезают в 96 МиБ; если не все влезли, над списком есть фраза и число оставшихся. Касание элемента другого этажа или раздела переключает сцену на его тайл. Пакет без таблицы `tiles` открывается целиком. На телефоне и на модели 7 ГБ не прогонялось.
- Проба OCCT (коробка 6 м³, BinTools 4494 байт) вшита в просмотрщик и прошла на телефоне Android 12 arm64. Это не M0 и не устройство уровня Note 10+.
- Иконка, шторка свойств поверх вида и публичные образцы `testdata/public/` — в main через #35. PR #24–#27 тем самым закрыты по сути.
- APK в git нет. Workflow «Android APK» собирает arm64 и кладёт файл артефактом Actions (push в `main` и `workflow_dispatch`). GitHub Release нет. Как отдавать пакет на телефон, не согласовано (#34).

## Проблемы и риски

- M0 не закрыт: нет STEP/XDE на устройстве, нет двух устройств и трёх моделей, нет FPS. Риск R1 (OCCT тяжёл) не снят. Проба коробки на Android 12 go/no-go не заменяет (#31).
- Картинка всегда меш Filament. Байты BinTools v4 читаются только чтобы выбрать подпись «точная» или «меш». `brep.pack` — AABB. Измерений нет.
- Ходьба по этажу не проверяет ни меш, ни точную геометрию: шаг проходит сквозь стены.
- Числовые NFR с пометкой [П] не подтверждались на устройстве. Модель до 7 ГБ IFC не проверялась. Запись ZIP без ZIP64, предел 4 ГиБ.
- В git оставлены пребилды `app/android/app/src/main/jniLibs/arm64-v8a/*.so` (OCCT 7.8.1, `libc++_shared`, `libocct_probe_jni`) и `assets/materials/*.filamat`. CI их не собирает; без `.so` в APK нет пробы OCCT. Сборка вручную: `tools/android_occt_probe/build_android.sh`.
- История git: pack около 83 МиБ, из них около 73 МиБ — старые APK. `git filter-repo` имеет смысл, если нужен меньший клон. Этот набор правок историю не переписывает.
- APK из Actions подписан debug-ключом раннера. Постоянной ссылки и GitHub Release нет (#34).
- Лицензия продукта не выбрана. OCCT на устройстве — LGPL (NFR-13).
